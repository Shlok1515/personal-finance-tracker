# Personal Finance Tracker

A Personal Finance Tracker built to help users manage their income, expenses, savings, and financial goals efficiently. The application provides an easy-to-use interface for recording transactions, tracking spending patterns, and gaining insights into personal finances.

## Features

- Add, edit, and delete income records
- Add, edit, and delete expense records
- Categorize transactions
- Track total income, expenses, and savings
- Interactive dashboard with financial summaries
- Monthly and yearly spending analysis
- Search and filter transactions
- Data visualization using charts and graphs
- Responsive and user-friendly interface

## Tech Stack

### Backend
